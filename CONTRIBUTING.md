# Contributing

This is a personal learning project — I'm not a developer by trade, and this repo documents my attempt to build a momentum trading scanner from scratch while figuring out Python, GitHub Actions, and Streamlit at the same time.

I'm not actively seeking contributors, but if you've spotted a bug, have a suggestion, or want to flag something that's broken, raising a GitHub Issue is the right way to do it. I'll look at it when I can.

## If you do want to suggest something

- Open an Issue describing what you've found or what you're proposing
- Keep it specific — "the breakout score calculation seems off because X" is useful; "you should add more features" is not
- I'm particularly interested in anything related to premarket data quality, yfinance reliability, or scoring model improvements

## What this project isn't

It's not a production trading system. It's not financial advice. It's one person's attempt to apply some logic to a problem and see what happens. The code reflects that — it works, it's reasonably well structured, but it was written by someone learning as they went.

## Forking

You're welcome to fork this and take it in whatever direction you want. If you build something interesting on top of it, I'd be curious to hear about it.
